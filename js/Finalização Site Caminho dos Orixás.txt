Finalização: Site Caminho dos Orixás
O site foi reconstruído com um design premium, utilizando Tailwind CSS para garantir fidelidade visual e performance. A estrutura foi pensada para ser de "Página Única" (Landing Page), facilitando a navegação via âncoras.

O que foi implementado
🎨 Design & Estética
Tema Personalizado: Cores Gold (ouro), Earth (terra) e Stone para um visual espiritual e elegante.
Animações: Efeito de "fade-up" na entrada dos elementos e um leve brilho ("glow") no nome principal.
Hero Section: Imagem de fundo mística gerada por IA com sobreposição de gradiente para garantir leitura do texto.
⚙️ Funcionalidade & Edição
Seção de Giras Dinâmica: Os cards de giras são gerados via JavaScript. Para alterar os dias ou horários semanalmente, basta editar o arquivo 
config.js
.
Seção Sobre Nós: Texto estruturado e fácil de atualizar, também controlado pelo arquivo de configuração.
Responsividade: Menu e layout totalmente adaptados para celulares e tablets.
Como Visualizar e Editar (Método Simplificado)
Abrir o site: Abra o arquivo 
index.html
.
Alterar as Giras e História:
Abra o arquivo 
js/config.js
.
Este é o seu Painel de Controle. Altere os textos entre aspas (ex: mude "Segunda-feira" para o tema da semana).
Salve o arquivo e atualize o navegador. O site mudará automaticamente!
Segurança: Quando você publicar o site, os visitantes verão apenas o resultado. Eles não terão acesso para alterar o arquivo config.js no seu servidor.
